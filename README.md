# STEMP21 CEO Daily Task Manager

Flutter Android starter project for a CEO daily task manager.

## Build
1. Install Flutter and Android Studio.
2. Run `flutter pub get`
3. Connect an Android phone/emulator.
4. Test with `flutter run`
5. Build Play Store bundle with `flutter build appbundle --release`
6. The AAB will be in `build/app/outputs/bundle/release/`.

This version stores tasks locally on the device.
